# Manuel test før udgivelse

Det, de automatiske tests ikke kan mærke. Tag 10 minutter på en rigtig telefon
(`npm start` og åbn LAN-adressen, eller den installerede app).

## Følelse og lyd
- [ ] Tryk på felter og tal føles hurtigt, uden forsinkelse eller dobbelt-zoom
- [ ] Lyde spiller efter første tryk (iPhone kræver et tryk først), og Lyd fra virker
- [ ] Fuldført række/kolonne/boks blinker guld, og sejrsbølgen ser pæn ud

## Skærm
- [ ] Hele pladen og alle 9 talknapper er synlige på en lille telefon (iPhone SE-størrelse)
- [ ] Vandret på tablet: plade til venstre, knapper til højre
- [ ] Mørkt tema: alle tal er tydelige, også valgt felt og fejl
- [ ] Notch og hjem-bjælke dækker ikke noget

## App
- [ ] Luk appen midt i en opgave → åbn igen → "Fortsæt" viser samme opgave og tid
- [ ] Flytilstand: appen starter og kan spilles (efter første åbning online)
- [ ] `?reklame=demo`: fuldskærmsreklame kommer kun mellem to spil og kan lukkes efter 5 sek.

## Opgaver
- [ ] Spil én opgave på hvert niveau til ende. Føles sværhedsgraden rigtig?
